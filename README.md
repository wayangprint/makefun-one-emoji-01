A tiny Node program that writes one emoji that stands for an AI agent — a puzzle piece, because an agent takes scattered pieces (a question, a file, a half-formed task) and fits them together into a finished whole — to /output/entry.txt for make.fun's Your Agent in One Emoji.

> 🧩

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
